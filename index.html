Cara Upload Aplikasi ke Domain Gratis

Aplikasi ini dibangun dalam 1 file mandiri (index.html) sehingga dapat langsung di-online-kan secara 100% gratis tanpa perlu menyewa server/VPS. Pilih salah satu cara termudah berikut:

1 Netlify Drop (Paling Cepat - Tanpa Coding/Git)

Rekomendasi
  1. Simpan kode aplikasi ini ke dalam sebuah folder di komputer Anda dengan nama file index.html.
  2. Buka situs app.netlify.com/drop dan daftar/login gratis.
  3. Tarik (drag & drop) folder berisi index.html tadi ke halaman Netlify.
  4. Dalam 5 detik, Anda akan mendapatkan link domain gratis seperti https://sipedas-sekolah.netlify.app yang siap dibagikan ke siswa!

2 GitHub Pages (Domain username.github.io)

  1. Buat akun gratis di github.com dan buat Repository baru bernama sipedas.
  2. Klik Add file → Upload files, lalu unggah file index.html.
  3. Masuk ke tab Settings → Pages, pada bagian Branch pilih main lalu klik Save.
  4. Website Anda aktif secara permanen dengan domain gratis https://username.github.io/sipedas.

3 Vercel (Domain .vercel.app)

Hubungkan repositori GitHub Anda ke vercel.com, klik Deploy, dan aplikasi otomatis online dengan sertifikat SSL (HTTPS) gratis.

Catatan Database: Saat ini data tersimpan di localStorage browser agar langsung berjalan tanpa konfigurasi server. Jika ingin data antar HP siswa dan komputer Admin tersinkronisasi secara online lintas perangkat, Anda dapat menghubungkan file ini ke database gratis seperti Firebase Firestore atau Supabase.
